GoF 设计模式 · 大白话图解

23 个经典设计模式，每个一页：用生活里的比喻讲明白它是什么、由什么组成、什么时候用。不堆术语，只说人话。

23 个模式 3 大分类 9 种语言实现对照 纯静态 · 无依赖
创建型（5 个）— 管"怎么生" 对象怎么造出来才省心：造几个、怎么造、造什么样的，都有讲究。
结构型（7 个）— 管"怎么搭" 类和对象怎么组合才好用：小零件拼成大结构，接口不匹配想办法接上。
行为型（11 个）— 管"怎么配合" 对象之间怎么分工沟通：谁负责什么、消息怎么传、活怎么派。

🏗️ 创建型 · Creational

关注对象的创建机制：把"造对象"这件事本身也设计好，免得 new 满天飞。

Abstract Factory

抽象工厂

一次订一整套配套的东西，换风格就整套换，绝不出现"现代沙发配古典茶几"。

建造者

复杂对象不一口吃成，而是一步一步搭出来，搭完一次性交货。

查看详解 → Factory Method

工厂方法

要什么跟工厂说一声就行，具体怎么造、造哪个，工厂自己定。

查看详解 → Prototype

原型

不从头造了：拿现成的复印一份，再改改就能用。

查看详解 → Singleton

单例

全局只此一份，谁来了见的都是同一个它。

🧱 结构型 · Structural

关注类与对象的组装：怎么把零件拼成好用的整体，接口不合时怎么接上。

Adapter

适配器

插头对不上插座？加个转换头，两边都不用改。

查看详解 → Bridge

桥接

两样东西各自变化太乱？分成两条线各变各的，中间架一座桥。

查看详解 → Composite

组合

整体和部分一个待遇：文件夹和里面的文件，用同一套办法操作。

查看详解 → Decorator

装饰器

不动原来的类，给它一层层"加料"：加一层，多一份本事。

查看详解 → Facade

外观

里面一堆按钮太吓人？开一扇门只留一个总开关。

查看详解 → Flyweight

享元

一百万棵树共用同一份纹理：一样的东西只造一份，大家共享。

查看详解 → Proxy

代理

先派个替身挡在前面，能挡的挡掉，挡不住再请正主出场。

🎭 行为型 · Behavioral

关注对象之间的职责分配与沟通方式：活怎么派、消息怎么传、状态怎么切。

Chain of Responsibility

责任链

请求沿着一条链往下传，能处理就接手，处理不了递给下一位。

查看详解 → Command

命令

把"要做的事"打包成物件：能排队、能撤销、能记账。

查看详解 → Interpreter

解释器

给一种小语言定好语法，句子来了逐条翻译执行。

查看详解 → Iterator

迭代器

不用知道容器内部长啥样，按顺序一个个往外拿。

查看详解 → Mediator

中介者

一群人两两私聊会乱成一团，不如拉个群，全只跟群主说话。

查看详解 → Memento

备忘录

游戏存档/读档：把对象某个时刻的状态拍成快照存起来，后悔了就恢复。

查看详解 → Observer

观察者

它一变，自动通知所有订阅它的人——公众号推送就是这么干的。

查看详解 → State

状态

不同状态下行为不同？把每个状态写成独立类，干掉一大坨 if-else。

查看详解 → Strategy

策略

同一件事有好几种做法，做法像插头一样随时换。

查看详解 → Template Method

模板方法

父类定好流程骨架，空出的步骤留给子类自己填。

查看详解 → Visitor

访问者

不动原来的类，把"新操作"做成访问者送上门来做。

🧭 怎么用这个站点

  1. 挑一个模式进去，先看"生活里的例子"——比喻懂了，模式就懂了一半。
